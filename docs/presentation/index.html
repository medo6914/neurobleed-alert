NeuroBleed Alert

نظام ذكي للكشف المبكر عن النزيف الدماغي: جهاز BLE طبي، تطبيق Flutter للهاتف والويب، لوحة تحكم إدارية، ومحرك ذكاء اصطناعي يتنبأ بالمخاطر لحظة بلحظة ويرسل إنذارات فورية.

المميزات

منظومة متكاملة من الجهاز الطبي إلى لوحة التحكم

🧠

AI Prediction

نموذج ذكاء اصطناعي يتنبأ باحتمالية النزيف الدماغي من قراءات الجهاز لحظياً.

📡

Real-time Monitoring

مراقبة حية للنبض، الأكسجين، ضغط الدم عبر WebSocket بلا تأخير.

📶

BLE Medical Device

ربط الجهاز الطبي عبر البلوتوث مع محاكاة كاملة للاقتران.

🚨

SOS Emergency

زر طوارئ يرسل الموقع والبيانات الحيوية مع العد التنازلي والاتصال المباشر.

🗺️

Hospital Navigation

خريطة تفاعلية مفتوحة المصدر (OpenStreetMap) تعرض أقرب المستشفيات مع البحث والاتجاهات.

📄

Medical Reports

تقارير طبية قابلة للتصفية والتصدير PDF وعرض مباشر.

🩺

Doctor Dashboard

لوحة أطباء: مرضى، أجهزة، قراءات حية، وتنبيهات خطورة.

🛡

Admin Dashboard

إدارة المستخدمين والمستشفيات والأدوار والأنظمة في لوحة ويب كاملة.

☁️

Cloud Backend

FastAPI + PostgreSQL مع Firebase للرسائل والإشعارات.
